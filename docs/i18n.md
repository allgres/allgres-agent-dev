# Languages and translation packs

English is the default and the source text. Other languages are **translation packs**: one JSON file per language in `web/i18n/`. The dashboard and the Canvas both read them. Pick a language in **Settings → Language** (kept for you in the database, so it follows you to any browser).

## File layout

```json
{
  "meta": { "code": "ko", "name": "Korean", "native": "한국어", "coverage": 81 },
  "sections": {
    "menu":   { "Chat": "채팅", "Approvals": "승인" },
    "Agents": { "New agent": "새 에이전트" },
    "canvas": { "Build your first team": "첫 팀을 만들어 보세요" }
  }
}
```

- `web/i18n/en.json` is the **reference**. Its sections list every string that can be translated (key and value are the same English text). Copy it, fill in the values, and you have a new language.
- The **English sentence is the key**, so the code never needs ids. A string with no entry, or a section left out, is shown in English. Nothing breaks when a pack is incomplete.
- Sections are only for keeping the file easy to edit: `menu`, `login`, `common`, `settings`, one per page (`Agents`, `Approvals`, …) and `canvas`. At run time the sections are merged; for the Canvas its own `canvas` section wins. Use `{name}`-style placeholders as in English.
- A language appears in Settings when its file is built in (`I18N_PACKS` in `src/lib.rs`) and `meta.code` matches the file name.

## Adding or fixing a translation

1. Edit `web/i18n/<code>.json` (add a line to the section next to the English one).
2. `python3 scripts/i18n_check.py ko` shows coverage and what is missing; `--missing` lists the strings; `--write` stores the percentage in the pack's `meta`.
3. Rebuild (the packs are compiled into the server).

New language: copy `en.json` to `<code>.json`, set `meta`, translate what you can, and add the file to `I18N_PACKS`.

## When the English text changes

Add the new string to `web/i18n/en.json`. `node scripts/i18n_extract.mjs` lists on-screen strings that `en.json` does not have yet, by page, from a running instance. A changed English sentence is a new key; the old line is reported as "not in en.json" by the checker and can be deleted.

## What is not translated

Long help paragraphs, server error messages and toasts that are not in the pack stay English, and so does anything you typed (agent names, prompts).
